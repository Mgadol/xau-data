# TradingView — шахалтын үзүүлэлт

`shahalt.pine` — Pine Script v6. Шахалт эхлэхэд дохио өгч, дээш задралын
оролт/стоп/зорилтыг зурж, самбарт төлөвийг харуулна.

## Суулгах

1. TradingView → Pine Editor
2. `shahalt.pine`-ийн бүх агуулгыг хуулж буулгах
3. **Save** → **Add to chart**
4. График: **XAUUSD, 1D**

Сэрэмжлүүлэг: цагны дүрс → «Шахалт эхэллээ» эсвэл «ДЭЭШ задрал — оролт».

## Лаан дээр юу харагдах вэ

| | |
|---|---|
| **Шар лаа** | шахагдсан үе |
| **Ногоон лаа** | задралын лаа |
| **Шар шошго** | «ШАХАЛТ 0.72» — шахалт эхэлсэн лаан дээр |
| **Ногоон шошго** | «ОРОЛТ / стоп / з1 / з2» — задралын лаан дээр бүх тоо |
| **Баруун талын шошго** | арилжаа явж байхад оролт, стоп, зорилтын түвшин |
| | задрал хүлээж байхад «ор 3345.2 · 3 бар» |

Шошго дээр хулганаа тавихад нэмэлт тайлбар гарна (эрсдэл, хил, хүлээх
хугацаа). Харагдац хэсгээс «Лааг будах», «Лаан дээр шошго» хоёрыг
тусад нь унтраана.

## Дүрэм

| | |
|---|---|
| Шахалт | ATR14 ÷ ATR100 ≤ 0.80 |
| Хил | 20 барын дундаж ± 1.5 ATR (өргөн нь яг 3 ATR) |
| Чиглэл | **ЗӨВХӨН ДЭЭШ** |
| Оролт | дээд хил дээр, баталгаа хүлээхгүй. Нээлт хэтэрсэн бол нээлтийн үнээр |
| Стоп | 2 ATR |
| Зорилт | 1 ATR (74% хүрнэ) → 4 ATR |
| Хүлээх | 5 бар. Ирэхгүй бол болих |

ATR нь **энгийн дундаж** — `ta.atr()` нь Уайлдерын жигдрүүлэлт тул
судалгаатай зөрдөг.

## Зөвхөн өдрийн график

`shinjilgee/e1_pine.py` нь `.pine` доторх төлөвт машиныг Python дээр яг
адилаар давтдаг. Түүгээр давхрага бүрийг жинхэнэ оролтын үнээр хэмжихэд:

| Давхрага | n | R | t | Ялсан | Жилд | Эерэг жил |
|---|---|---|---|---|---|---|
| 1 цаг | 2119 | −0.125 | **−4.58** | 35% | 132 | 4/17 |
| 2 цаг | 672 | +0.069 | +1.39 | 43% | 42 | 12/17 |
| 3 цаг | 532 | −0.016 | −0.28 | 39% | 33 | 8/17 |
| 4 цаг | 324 | +0.002 | +0.02 | 39% | 20 | 7/16 |
| 6 цаг | 231 | −0.006 | −0.07 | 39% | 15 | 8/16 |
| 8 цаг | 140 | +0.138 | +1.29 | 44% | 9 | 13/16 |
| **Өдөр** | **66** | **+0.547** | **+3.48** | **61%** | **3** | **12/20** |

1 цаг нь **салж алдагдалтай**. Бусад нь тэгд ойр. Өдрийн график
ганцаараа үлдэв:

```
95% итгэлийн завсар   +0.239 … +0.854R
bootstrap 20000       тэгээс дээш байх магадлал 100%
2005–2015 +0.471R     2016–2026 +0.622R
сайн 5 арилжааг хассан ч +0.428R
спред $1.00-д ч +0.521R
```

## Юуг хассан, яагаад

Бүгдийг энэ кодын логик дээр тусад нь хэмжив (өдрийн график):

| Хувилбар | n | R | t |
|---|---|---|---|
| **зөвхөн шахалт** | **66** | **+0.547** | **+3.48** |
| + хөлийн чиглэл (d1) | 60 | +0.556 | +3.36 |
| + байрлалын шүүлтүүр (d3) | 64 | +0.517 | +3.20 |
| + хоёул | 60 | +0.551 | +3.30 |

Аль нь ч R-ийг нэмээгүй, арилжааг цөөрүүлж t-г бууруулсан. Тиймээс
хасав: **байрлалын шүүлтүүр, хөл/зигзаг, идэвхийн чиглэл, сесс.**

d3-ийн +0.810/+0.460/+0.064R нь шахагдсан бар БҮРЭЭР хуваасан тоо;
задрал болох мөчид анкр нь өмнөх шахагдсан бар тул байрлал аль хэдийн
дээгүүр байдаг — шүүлтүүр болж чаддаггүй.

Урьд нь шалгалт даваагүй тул огт ороогүй: Фибоначчи, макро өгөгдөл,
машин сургалт, Dow, Elliott, олон давхрага нийцүүлэх, баталгааны буфер,
дугуй тоо, pivot, өчигдрийн дээд/доод.

## e1-д илэрсэн ЗАСВАР

d3 ба d5-ийн `collect()` нь **нээлтийн үнийг огт хардаггүй** тул бар
хилээс дээш нээгдсэн ч «хил дээр орлоо» гэж тооцдог байжээ. c8-д яг энэ
алдаа нэг удаа зассан (+0.527R → +0.219R) боловч дамжаагүй.

| Давхрага | d5-ийн таамаг | Жинхэнэ |
|---|---|---|
| 4 цаг | +0.473 | +0.188 |
| Өдөр | +0.804 | +0.551 |

Доод давхрагад бар богино тул хил ойрхон, үнэ түүнийг үсэрч гардаг нь
олон — **доод давхрагын ирмэг бүхэлдээ тэр таамгаас гарч байжээ.**

Хилийг алгасах нь бас буруу: R нь +0.547-оос +0.466 болж БУУРНА. Орох нь
зөв, гэхдээ нээлтийн үнээр.

## Өдрийн барын хил

Судалгаанд өдрийн хилийг таамаглалгүйгээр хэмжсэн: гаднаас ирсэн дээжийн
30 өдрийн үнэтэй тулгаж, хилийг 0–23 цагаар гүйлгэхэд 18:00 UTC
(Нью-Йоркийн 17:00 хаалт) нь $1.27, шөнө дунд нь $2.62 зөрүүтэй гарсан.
TradingView-ийн OANDA:XAUUSD өдрийн бар яг тэр хаалтыг барина.

## Шалгах

```
python3 shinjilgee/e1_pine.py            # өдрийн график, бүрэн задаргаа
python3 shinjilgee/e1_pine.py --tf 4h    # 4 цаг
python3 shinjilgee/e2_davhraga.py        # бүх давхрага зэрэгцүүлсэн
```

Pine кодыг өөрчлөх бол **эхлээд `e1_pine.py::pine()`-д өөрчилж тоог нь
хараад** дараа нь Pine руу буулга.

## Хязгаар

- Жилд ердөө ~3 тохиргоо
- Ирмэг нь алтны урт хугацааны **өсөлтөөс** ирдэг. 2012–2015 буурлын үед
  ашиг ~0 болсон
- Задралын **12% нь 0.5 ATR ч явахгүй** унтардаг
- Богино тал бүх тестэд алдагдалтай — код нь зөвхөн тэмдэглэнэ
