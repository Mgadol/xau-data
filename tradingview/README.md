# TradingView — шахалтын үзүүлэлт

`shahalt.pine` — судалгааны батлагдсан дүрмүүдийг Pine Script v6 болгосон
үзүүлэлт. Шахалт эхлэхэд дохио өгч, задралын оролт/стоп/зорилтыг зурж,
хяналтын самбарт төлөвийг харуулна.

## Суулгах

1. TradingView → Pine Editor
2. `shahalt.pine`-ийн бүх агуулгыг хуулж буулгах
3. **Save** → **Add to chart**
4. График: **XAUUSD, 1D** (доорх шалтгааныг үз)

Сэрэмжлүүлэг: цагны дүрс → «Шахалт эхэллээ» эсвэл «ДЭЭШ задрал — оролт».

## Гол дүрэм

| | |
|---|---|
| Шахалт | ATR14 ÷ ATR100 ≤ 0.80 |
| Хил | 20 барын дундаж ± 1.5 ATR (өргөн нь яг 3 ATR) |
| Чиглэл | **ЗӨВХӨН ДЭЭШ** |
| Оролт | дээд хил дээр, баталгаа хүлээхгүй. Нээлт хэтэрсэн бол нээлтийн үнээр |
| Стоп | 2 ATR |
| Зорилт | 1 ATR (74% хүрнэ) → 4 ATR |
| Хүлээх | 5 бар. Ирэхгүй бол болих |

## Аль давхрага дээр ажиллуулах вэ

`shinjilgee/e2_davhraga.py` нь ЯГ энэ кодын логикоор бүх давхрагыг
жинхэнэ оролтын үнээр хэмжсэн:

| Давхрага | R | Ялсан | Жилд | Эерэг жил |
|---|---|---|---|---|
| 1 цаг | +0.03 | 41% | 67 | 10/17 |
| 2 цаг | +0.22 | 48% | 23 | 14/17 |
| 3 цаг | +0.17 | 46% | 17 | 8/17 |
| 4 цаг | +0.19 | 45% | 12 | 9/16 |
| 6 цаг | +0.09 | 42% | 9 | 8/15 |
| 8 цаг | +0.11 | 44% | 6 | 9/15 |
| **Өдөр** | **+0.55** | **60%** | **3** | **13/20** |

**Зөвхөн өдрийн график.** 1 цагийнх $0.50 спредэд сөрөг болно.

Өдрийн тоо статистикийн хувьд бат: n=60, t=3.30, 95% итгэлийн завсар
+0.224…+0.879R, хоёр хагас үе хоёулаа эерэг (+0.425 / +0.687), хамгийн
сайн 5 арилжааг хассан ч +0.420R.

## Өдрийн барын хил

Судалгаанд өдрийн хилийг **таамаглалгүйгээр хэмжсэн**: гаднаас ирсэн
дээжийн 30 өдрийн үнэтэй тулгаж, хилийг 0–23 цагаар гүйлгэн шалгахад
18:00 UTC (Нью-Йоркийн 17:00 хаалт) нь $1.27 зөрүүтэй, шөнө дунд нь
$2.62 зөрүүтэй гарсан. TradingView-ийн OANDA:XAUUSD өдрийн бар яг тэр
хаалтыг барьдаг тул тохирно. Өөр брокерын тэжээл өөр цагт тасалбал
тоонууд бага зэрэг хөдөлнө.

## Шалгалтын хэрэгслүүд

```
python3 shinjilgee/e1_pine.py            # өдрийн график, бүрэн задаргаа
python3 shinjilgee/e1_pine.py --tf 4h    # 4 цаг
python3 shinjilgee/e2_davhraga.py        # бүх давхрага зэрэгцүүлсэн
```

`e1_pine.py::pine()` нь `.pine` доторх төлөвт машиныг Python дээр яг
адилаар давтдаг. Pine кодыг өөрчлөх бол **эхлээд энд өөрчилж, тоог нь
хараад** дараа нь Pine руу буулга — эс бөгөөс өөрчлөлт сайн уу муу юу
гэдгийг мэдэхгүй.

## e1/e2-д илэрсэн ЗАСВАР

d3 ба d5-ийн `collect()` нь нээлтийн үнийг огт хардаггүй тул бар хилээс
ДЭЭШ нээгдсэн ч «хил дээр орлоо» гэж тооцдог байжээ. c8-д яг энэ алдаа
нэг удаа баригдаж зассан (+0.527R → +0.219R) боловч дараагийн
шинжилгээнд дамжаагүй байв.

Жинхэнэ оролтын үнээр:

| Давхрага | d5-ийн таамаг | Жинхэнэ | Зөрүү |
|---|---|---|---|
| 1 цаг | +0.202 | +0.026 | −0.176 |
| 4 цаг | +0.473 | +0.188 | −0.285 |
| 8 цаг | +0.442 | +0.111 | −0.330 |
| Өдөр | +0.804 | +0.551 | −0.252 |

Доод давхрагад бар богино тул хил ойрхон, үнэ түүнийг үсэрч гардаг нь
олон — тиймээс гажуудал нь тэнд хамгийн том. **Доод давхрагын ирмэг нь
бүхэлдээ тэр таамгаас гарч байжээ.**

Мөн хэмжигдсэн: байрлалын шүүлтүүр энэ хэрэгжилтэд бараг ажиллахгүй
(≥0.50 → +0.551R, ≥0.67 → +0.571R, шүүлтгүй → +0.556R), учир нь анкр нь
задралын өмнөх шахагдсан бар тул байрлал тэр үед аль хэдийн дээгүүр
байдаг. Самбарт мэдээлэл болгон үлдээсэн.

## Хязгаар

- Ирмэг нь алтны урт хугацааны **өсөлтөөс** ирдэг. 2012–2015 буурлын үед
  шахагдсан бүлгийн ашиг ~0 болсон (харин тэлсэн бүлэг −0.33R).
- Задралын үргэлжлэл маш тархсан: 5%-д 0.21 ATR, медиан 1.75, 95%-д
  7.97. **12% нь 0.5 ATR ч явахгүй унтардаг.**
- Богино тал бүх тестэд алдагдалтай. Код нь доош задралыг зөвхөн
  мэдээлэл болгон тэмдэглэнэ.
- Жилд ~3 тохиргоо. Тэвчээр шаардана.
